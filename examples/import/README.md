# Примеры файлов для ручной проверки

Обе книги входят в репозиторий и предназначены для сквозной проверки импорта через
веб-интерфейс. Сначала импортируйте базовую книгу, затем книгу с конфликтами и
ошибками. В каждой книге есть лист `Инструкция` с ожидаемыми результатами.

## `01_base_import.xlsx`

Проверяет основной сценарий импорта, русские и английские заголовки, разные
допустимые форматы телефона, email и скидки, пустые значения, выбор Excel-листа и
объединённые ячейки.

Рекомендуемый первый запуск: лист `01_База`. После подтверждения в PostgreSQL
должно появиться восемь контактов; строка без телефона будет пропущена, а пустая
строка не попадёт в импорт.

## `02_conflicts_and_errors.xlsx`

Используется после импорта `01_База`. Первый лист покрывает совпадения, новые
контакты и решения конфликтов `skip`, `replace`, `merge`. Остальные листы
изолированно проверяют ошибки телефона, email и скидки, дубликаты, неоднозначные,
пустые и повторяющиеся заголовки, отсутствие телефонной колонки, таблицу без строк
и полностью пустой лист.

Для проверки отдельного сценария укажите точное имя листа в поле «Лист Excel».
